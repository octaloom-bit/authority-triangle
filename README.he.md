# משולש הסמכות

🇬🇧 [English](README.md)

**סקיל של קלוד שכותב פוסט בלינקדאין באחד משלושה מבנים, רק מחומר שנתתם לו.**

עובד בעברית ובאנגלית. בלי מפתחות API ובלי התקנה מעבר להעתקת תיקייה.

נבנה על ידי [OctaLoom](https://octaloom.com). חינם לשימוש ולהתאמה.

---

## שלוש הצלעות

| מבנה | מה הקורא רואה | מה זה בונה |
|---|---|---|
| **הצגת עבודה** | איך הגעתם לתוצאה, עם ההחלטות ועם מה שהשתבש | אמון |
| **המדריך המקצועי** | שיטה שאתם עובדים איתה, שלב אחרי שלב, בגוף ראשון | מומחיות |
| **שובר המוסכמות** | עצה מקובלת שאתם חולקים עליה, מתוך מקרה מהעבודה | בידול |

שלושתם נשענים על אותו רעיון: סומכים על איש מקצוע אחרי שרואים איך הוא חושב. תוצאה לבדה מראה מעט מזה, ועצה כללית אפשר למצוא בגוגל.

## איך הסקיל עובד

1. **שואל לפני שהוא כותב.** 6 שאלות שמוציאות את החומר, בעיקר מה השתבש ואיזה מספר עומד מאחורי התוצאה. על תשובה כללית כמו ״הלקוח היה מרוצה״ הוא מבקש דוגמה.
2. **כותב רק ממה שקיבל.** מספר, לקוח או ציטוט שלא מסרתם לא ייכנסו לפוסט. פרט שחסר מסומן `[חסר: ...]`.
3. **בודק את הטיוטה.** 15 בדיקות לדפוסים שגורמים לעברית להישמע כמו AI: משפטים קצרים ברצף, שלשות, ״זה לא X, זה Y״, ״רוב האנשים״ וסיום שנראה כמו פוסטר מוטיבציה. שורה שלא עוברת נכתבת מחדש.
4. **מחזיר פוסט ושתי גרסאות לשורה הראשונה.**

דוגמה לפוסט מכל מבנה נמצאת בתיקייה `examples/`.

## התקנה

**Claude Code**

```bash
git clone https://github.com/octaloom-bit/authority-triangle.git ~/.claude/skills/authority-triangle
```

ואז בשיחה חדשה: ״פוסט הצגת עבודה על הפרויקט האחרון שלי״.

**Claude בדפדפן או באפליקציה**

מורידים את הריפו כקובץ ZIP (הכפתור הירוק Code ← Download ZIP), ומעלים אותו ב-Settings ← Capabilities ← Skills.

**ChatGPT, Gemini או כל צ׳אט אחר**

מספיק להעתיק. בתיקייה `prompts/` יש שלושה פרומפטים עצמאיים, אחד לכל מבנה, ומדביקים אותם בתחילת שיחה חדשה.

## מה יש בתיקייה

```
SKILL.md                     התהליך: בחירת מבנה, ראיון, כתיבה, בדיקה

references/hebrew-gate.md    הבדיקות, עם דוגמאות
prompts/                     שלושת הפרומפטים העצמאיים
examples/                    פוסט לדוגמה מכל מבנה
```

## גבולות הסקיל

הוא בודק דפוסים של כתיבה שנשמעת כמו AI, ולימוד עמוק של הקול שלכם נשאר לכלים אחרים: hebrew-writer של אמיר בלדיגה, או [linkedin-bestie](https://github.com/octaloom-bit/linkedin-bestie), שבונה פרופיל קול ומתכנן רצף תוכן שלם.
